# News Admin UX Improvements Design Spec

## Goal Description
Improve usability and UX of the News Create and Edit pages:
1. **Remove Slug Input**: Hide slug input field from the UI. Auto-generate the slug from the Title behind the scenes and update the form state dynamically.
2. **Rich Text Editor for Body**: Replace the raw HTML `<Textarea>` with a clean, lightweight, custom Rich Text Editor component built with standard React and HTML5 `contentEditable`. This will allow non-technical admin users to write formatted text without needing to write HTML manually.

---

## Technical Details & UI Features

### 1. Auto-Slug Generation
- Slug is generated by cleaning, lowercasing, and replacing spaces/special characters in the title.
- Updated instantly on `title` change.
- In both `Create.tsx` and `Edit.tsx`, the visual input is completely removed, but the form state `data.slug` is sent to the backend.

### 2. Custom Rich Text Editor Component (`RichTextEditor`)
We will create a reusable component in `resources/js/components/RichTextEditor.tsx`.

#### Editor Features:
- **Toolbar Actions**:
  - Headings: H2, H3
  - Bold, Italic, Underline, Strikethrough
  - Lists: Bullet List, Numbered List
  - Alignment: Left, Center, Right, Justify
  - Insert Link (prompting for URL)
  - Clear Formatting
  - Toggle HTML source code view (icon button to toggle back to raw textarea for advanced admins)
- **Visuals**:
  - Focus rings matching the rest of the UI (Emerald/Green colors).
  - Premium border/toolbar styled using Tailwind and Lucide icons.
  - Placeholder text.
  - Safe HTML loading on initialize and update.
